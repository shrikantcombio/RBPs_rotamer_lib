# Backbone and side-chain torsion scatter plots

Descriptive companions to `figures/backbone_deviation/`. The statistical tests are in
`script/backbone_deviation.py`; these figures only show the raw distributions.

Generated by `script/backbone_scatter_plot.py`:

```bash
python script/backbone_scatter_plot.py              # all plots, ~2.5 min
python script/backbone_scatter_plot.py --plots 3d   # or: ramachandran
```

## Data

`output_files/torsion_dataset/PRDBv3_187_bound_unbound_protein_torsions.json` (from `script/calculate_187_prdbv3_protein_torsions.py`): 187 PRDBv3 complexes,
bound (X-ray) and unbound (X-ray; NMR for 14 complexes) residues paired.

- Missing angles are empty in this file and are left out of each plot.
- The earlier input, `PROTEIN_BACKBONE_SIDECHAIN_TORSION_ANGLES_187_clean.tsv`, stored missing
  χ as 0.0 (12,512 χ2 values) and had no core region. It is no longer used.

## Figures

### `3d_projections/<AA>_<region>_chi<n>_3D_projection.png`

- Axes: Δφ, Δψ and Δχn (bound − unbound, signed shortest arc).
- One plot per residue type, χ1–χ4, and region (I interface, N non-interface surface, C core).
- n is given in each title.

### `ramachandran/Only_B_*.png` and `Only_U_*.png`

- φ/ψ of bound or unbound residues, coloured by χn on a cyclic colour scale.
- One row per residue, one column per χ.

### `ramachandran/<AA>_side_by_side_bound_unbound_scatter.png`

- The same plots with bound and unbound side by side, one row per χ.

## Conventions

- **Symmetric terminal χ.** ASP χ2, GLU χ3, PHE χ2 and TYR χ2 are two-fold symmetric (OD1/OD2,
  OE1/OE2, ring flip). They are coloured in their canonical 180° range, and their Δχ is taken
  mod 180°, so a relabelling does not appear as a 180° change. Panel titles say "mod 180°".
- **ARG χ5.** Planar guanidinium (NH1/NH2 equivalent), so it has no rotamers and is not plotted.
